# Математика #7 — сайт

У репозиторії мають бути лише ці файли (картинки окремо класти не треба — вони вже всередині сторінок):

| Файл | Що це |
|---|---|
| `index.html` | Обкладинка: острів, заголовок «Математика #7», компас «Наш маршрут» |
| `karta.html` | Ментальна карта: 24 заняття, 7 розділів, картки тем |
| `README.md` | Цей опис (необов'язковий) |

## Важливо
- Обидва файли лежать в одній папці (у корені репозиторію).
- Назви не змінювати: компас веде на `karta.html`, а кнопка «← на острів» — на `index.html`.
- Малюнок острова і шрифти обкладинки вбудовані у `index.html`, тому інтернет для них не потрібен.
- Шрифти ментальної карти підвантажуються з Google Fonts (потрібен інтернет).

## Як опублікувати на GitHub Pages
1. Завантажте `index.html` і `karta.html` у корінь репозиторію (Add file → Upload files → Commit).
2. Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)` → Save.
3. Через 1–2 хвилини сайт буде за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
4. Цю адресу можна вставити в Google Сайт: Вставити → Вбудувати → URL.
